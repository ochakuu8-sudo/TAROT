# タロット

78枚のタロットから、正位置・逆位置つきで均等にランダムで引けるシンプルなPWAです。
ビルド不要の静的ファイルだけでできていて、一度開けばオフラインでも動きます。

- スプレッド：ワンオラクル / ケルト十字
- 「引き直す」で何度でも引き直し（保存はしません）
- 引いた後、下の「結果をコピー」で一覧をテキストでコピー

```
ケルト十字
1. 現状：ワンドのペイジ（逆位置）
2. 障害・試練：ペンタクルの6（正位置）
…
```

## 抽選のしかた

- 78枚を `crypto.getRandomValues` を使ったフィッシャー–イェーツ法でシャッフルし、上から必要枚数を取ります（同じカードは出ません）
- 乱数は剰余の偏りが出ないよう棄却法で整数にしています
- 正位置・逆位置は1枚ごとに独立して 1/2

## 使い方

### スマホにアプリとして入れる（GitHub Pages）

1. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして保存
2. 表示された URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）をスマホで開く
3. iPhone は Safari の共有 →「ホーム画面に追加」、Android は Chrome のメニュー →「アプリをインストール」

### PCでローカルに動かす

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く（ここからもインストール可）
```

`index.html` をダブルクリックで直接開いても使えます（その場合オフラインキャッシュとインストールは無効）。

## カスタマイズ

- スプレッドを増やす：`app.js` の `SPREADS` に追加します。`layout: 'grid'` なら枚数ぶん並べて表示します
  ```js
  { id: 'three', name: 'スリーカード', layout: 'grid', positions: ['過去', '現在', '未来'] },
  ```
- ファイルを更新したら `sw.js` の `CACHE` の番号（`tarot-v1` → `tarot-v2`）を上げると、インストール済みのアプリにも反映されます
